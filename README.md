# 西湖羽翼 (West Lake Wings) 🐦🌿

西湖羽翼是一个专为杭州西湖鸟类与植物观察者设计的极简主义互动 Web 应用。它结合了“中国国家地理”式的审美风格与现代全栈技术，旨在记录西湖全域（包括杨公堤、西湖群山）的每一次自然邂逅。

## ✨ 核心特性

- **艺术级俯视地图**：采用精致的 CartoDB Voyager 矢量风格地图，支持高倍率缩放，清晰展现西湖建筑与植被。
- **智能物种识别**：输入“乌鸫”、“荷花”、“鸳鸯”等关键词，地图标记会自动动态适配对应的 Emoji 形象（🐦‍⬛, 🪷, 🦆 等）。
- **专业科学档案**：参考科学期刊设计的观测卡片，支持自适应照片比例显示（横图/竖图），自动记录经纬度与观测时间。
- **数据备份**：支持将所有观测记录一键导出为 JSON 文件进行存档。

## 🛠️ 技术栈

- **框架**: React + Vite
- **语言**: TypeScript
- **样式**: Tailwind CSS
- **地图**: MapLibre GL JS
- **图标**: Lucide React
- **字体**: Noto Serif SC, Playfair Display

## 🚀 快速开始

### 1. 环境准备
确保您的环境中已安装 [Node.js](https://nodejs.org/)。

### 2. 安装与运行
```bash
# 安装依赖
npm install

# 启动本地开发环境
npm run dev

# 构建生产版本
npm run build
```

## 📖 使用指南

1. **记录观察**：在地图上点击您发现生物的具体位置。
2. **填写信息**：在弹出的表单中选择时间、类别（动/植）并输入物种名称。
3. **上传照片**：点击相机图标上传现场拍摄的照片（支持自动适配比例）。
4. **查看与管理**：点击地图上的 Emoji 标记查看详细档案，或点击右上角列表图标管理历史记录。
5. **撤销记录**：在详情卡片或历史列表中均可点击删除/撤销按钮。
